# 口袋鱼缸操作手册

适用设备为立创实战派 ESP32-S3 N16R8，屏幕为 320×240 ST7789 触摸屏。本手册对应本项目的 ESP-IDF 6.0.2 汉化适配版本，整理日期为 2026-11-12。

## 1. 快速开始

1. 使用 USB Type-C 数据线连接开发板与电脑或 USB 电源。
2. 等待鱼缸完成初始化。启动期间会加载本地模型并准备水草动画。
3. 首次运行时，按屏幕上的提示为两条小鱼选择名字、体型、鱼鳍、颜色和花纹。
4. 完成引导后，轻点水面投食，轻点鱼儿查看状态。

基础养鱼功能可离线运行。本板新建鱼缸从两条鱼开始，常驻鱼数量上限为三条。鱼苗成长为幼鱼、成鱼和老鱼时，大小、花纹与鳍尾会逐渐变化。

首次启动的默认音量为零。调整音量后，后续启动使用保存值。屏幕中的名字采用字母输入，既有鱼名与鱼缸名会从存档载入。

## 2. 首次设置

### 名字

- 上下滑动字母滚轮，或使用页面上的字母键选择名字。
- 鱼名最多输入七个英文字母。
- 点“删除”修改输入，点“下一步”进入后续页面。

### 外观

- “体型”可选择经典、纤长或圆润。
- “鱼鳍”可选择经典、飘逸长鳍或高帆鳍。
- “身体”和“花纹”用于调整配色。
- 点“随机”可重新组合外观，点“换色”可调整身体与花纹的配色关系。
- 成年预览展示成长后的外观。鱼苗会先保留较简洁的鳍尾与花纹。

设置完成后，点“开始养鱼”。

## 3. 触摸操作

以下操作适用于鱼缸主画面。投食使用上沿水面，切换灯光和敲击玻璃使用水面下的空白区域。

| 操作 | 效果 |
| --- | --- |
| 轻点上沿水面 | 在附近投放饲料 |
| 轻点一条鱼 | 打开它的信息卡 |
| 轻点空白处 | 关闭当前信息卡 |
| 持续按住玻璃几秒钟 | 信任你的鱼儿会靠近手指 |
| 双击空白玻璃 | “关灯”设为“双击”时切换灯光 |
| 在空白玻璃上快速连续敲击三次 | 惊动附近的鱼儿 |
| 拖动手指擦过玻璃 | 擦除划过位置的藻类 |
| 横向划过水草 | 在手指经过的高度修剪水草 |

### 清洁与修剪工具

打开鱼的信息卡后，可以在工具区选择海绵或剪刀。

- 海绵用于清洁玻璃。
- 剪刀用于修剪水草。
- 使用完后，点屏幕上的“完成”放下工具。

放下工具后可以继续投食、打开鱼卡和切换灯光。

### 喂食与陪伴

鱼儿会按自身的饥饿、体力、性格和当前环境选择行为。状态发生明显变化时，模型会重新决策，单次决策通常需要几秒。游动与鳍尾动画会持续运行。

轻点水面可以亲手喂食。开启“自动投食”后，系统会按饥饿情况补充食物。持续安静地按住玻璃有助于建立信任，频繁惊吓会降低信任。

## 4. 查看鱼儿与成长记录

轻点鱼儿打开信息卡。卡片中的主要图标和进度条表示以下状态。

| 状态 | 阅读方式 |
| --- | --- |
| 饱腹度 | 越满表示越饱，随饥饿增加而减少 |
| 体力 | 越高表示越有精神 |
| 压力 | 越高表示越紧张 |
| 信任 | 越高表示越信任你的陪伴 |
| 胆量、合群、好奇 | 随观察到的行为逐渐揭示 |

点“详情”进入成长与里程碑页面。这里可以查看成长阶段、已经完成的行为记录和新鱼苗的到来条件。

新鱼苗需要满足页面中列出的照料条件，包括信任、喂食、陪伴、成长、水草和玻璃清洁程度。条件满足后，鱼儿会在水草间繁育。

在详情页面点鱼的名字，可以进入改名、出售等操作。出售需要再次点击确认，鱼缸至少保留两条鱼。

## 5. 常用菜单

从“详情”页面底部的图标进入商店、设置、我的鱼缸和访客图鉴。

### 商店

照料鱼儿、修剪水草、清理藻类以及完成成长事件，可以获得沙币。

商店分为装饰、小生物和背景等分类。选择物品后，可查看价格、用途和当前状态。已拥有的可摆放装饰可以移动、调整前后层次或收纳。

放置装饰时，左右拖动调整位置，使用“前方”“中间”“后方”等选项调整层次，最后点“完成”。

### 设置

| 选项 | 用途 |
| --- | --- |
| 亮度 | 调整屏幕背光 |
| 音量 | 调整声音，零音量显示为“关” |
| 关灯 | 选择双击控制，或按静置时长自动关灯 |
| 自动投食 | 开启或关闭自动补充食物 |
| 自动旋转 | 锁定当前方向或允许姿态感应切换方向 |
| 联机 | 进入相邻鱼缸连接页面 |
| 更新 | 进入更新信息页面 |

亮度与音量调整后会保存。本板当前固件更新使用本手册第 8 节的数据线方式。

### 我的鱼缸

在“我的鱼缸”中，可以查看当前鱼缸、切换收藏架上的鱼缸、改名，以及管理鱼缸库。默认鱼缸名显示为“我的鱼缸”或“鱼缸＋编号”，自定义名称沿用存档。访客护照中的系统家园名称也使用中文。收纳页面提供时间暂停或休眠式继续生活等选项，按页面文字选择。

触摸锁会限制主画面的触摸操作。连按两次 BOOT 打开“我的鱼缸”，通过锁图标解除触摸锁。

### 访客图鉴与联机

访客图鉴用于查看到访过的鱼儿及其记录。

使用兼容的另一台鱼缸设备时，在两台设备上打开“联机”，将设备并排放置，按提示长按相邻的发光箭头。连接完成后，鱼儿可以通过通道往来。

赠送鱼儿时，接收方需要确认。按页面提示完成赠送或取消请求。

## 6. 开发板按键

| 按键操作 | 效果 |
| --- | --- |
| 按 RESET | 重启并载入存档 |
| 短按一次 BOOT | 等待双击判断窗口结束后进入休眠 |
| 快速连按两次 BOOT | 打开或关闭“我的鱼缸” |
| 休眠时按 BOOT | 唤醒设备 |
| 主画面中按住 BOOT 约五秒，再点屏幕 | 打开重置确认框 |
| 设置页中按住 BOOT 约五秒，再点屏幕 | 打开高级设置 |

重置确认框中的“是”会清除鱼缸进度并重新开始。选择“否”返回当前鱼缸。

BOOT 双击要求第二次按下在第一次松开后的约 0.4 秒内开始。使用长按组合时，先按住 BOOT 满五秒，再让手指落到屏幕上。

高级设置包括触摸校准等选项。校准时，按顺序点击每个十字的中心，再按提示确认新校准。

本板使用 USB 供电。高级界面中的电池选项沿用上游设计。

## 7. 存档与日常使用

鱼名、外观、成长和照料进度会自动保存。普通照料事件通常合并到约三十秒的存档窗口，购买、出售、改名等重要操作会在完成时保存。

重新上电后，程序载入保存的鱼缸与设置。正常游戏的状态来自本地 Flash 存储。

## 8. 构建、烧录与调试

在本项目根目录打开终端。

### 构建固件

```console
python tools/idf_szpi.py build
```

脚本使用本机已注册的 ESP-IDF 6.0.2。签名密钥位于 `firmware/keys/ota_signing_key.pem`，可与工程一起备份。

### 首次完整烧录

本次测试端口为 CH340K 的 COM33。后续连接时，以设备管理器中实际显示的端口替换下面的 `COMx`。

```console
python tools/idf_szpi.py -p COMx flash monitor
```

完整烧录会写入引导程序、分区表、应用和模型。模型文件较大，首次写入需要数分钟。

### 后续应用更新

```console
python tools/idf_szpi.py -p COMx app-flash
```

此命令更新应用，沿用已有模型分区。程序启动后会载入既有存档。

### 串口调试

串口参数为 115200、8N1。退出 IDF monitor 使用 Ctrl+]。

| 命令 | 用途 |
| --- | --- |
| `state` | 查看鱼儿状态和位置 |
| `snd off` | 静音并保存音量设置 |
| `fps reset` | 开始新的帧间隔统计窗口 |
| `fps` | 查看帧率、最长帧间隔和慢帧数量 |
| `profile on` | 开启详细运行日志 |
| `profile off` | 切回日常精简日志 |
| `reboot` | 保存当前鱼缸并重启 |

日常动画使用精简日志。测量帧率时，先发送 `fps reset`，让主画面运行几十秒，再发送 `fps`。详细日志用于排查问题，排查结束可发送 `profile off` 恢复日常状态。

### 官方 LCD 独立测试

```console
python tools/idf_szpi.py -D PT_LCD_TEST=ON -p COMx app-flash
```

该测试显示红、绿、蓝、白四色，保持功放关闭。测试结束后，使用普通 `app-flash` 命令恢复鱼缸应用。

## 9. 常见情况

| 现象 | 处理方法 |
| --- | --- |
| 屏幕变暗 | 检查亮度与“关灯”模式。手动模式下可在水面下的空白玻璃处双击开灯 |
| 触摸被锁定 | 连按两次 BOOT 打开“我的鱼缸”，点锁图标解除 |
| 点击位置偏移 | 进入高级设置进行触摸校准 |
| 声音关闭 | 当前默认静音，可在设置中调整音量 |
| 鱼暂时没有靠近手指 | 先喂食，再安静按住玻璃几秒，信任会逐渐建立 |
| 鱼苗花纹较简单 | 外观会随着成长逐渐展开 |
| 烧录提示端口被占用 | 结束正在使用该串口的监视器，再执行烧录命令 |
| 固件更新后需要确认画面 | 运行官方 LCD 测试，或通过串口查看启动信息 |

显示、触摸、默认静音、本地推理和存档载入已完成板上验证。双板联机和扬声器播放效果尚未实测。
