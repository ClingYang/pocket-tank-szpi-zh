# 验证记录

验证日期为 2026-11-11 至 2026-11-12，目标为立创实战派 ESP32-S3 N16R8。

2026-11-12 的汉化补丁已通过 ESP-IDF 6.0.2 构建、镜像检查和 RSA 签名校验。随后在 COM33 完成应用烧录并通过 Flash 哈希校验。启动日志中的 ELF SHA-256 与当前镜像一致，模型与显示、触摸驱动完成初始化，音量为 0。设置页和“我的鱼缸”收藏架已按 320×240 原生像素回读，中文按钮、版本信息和默认鱼缸名称显示完整。以下长时间性能统计来自用户已接受的前一版动画固件。

## 构建与镜像

- ESP-IDF 6.0.2、Xtensa GCC 15.2.0 构建通过。最终应用为 firmware/build-szpi/pocket_tank.bin，大小 2,428,928 字节，应用分区剩余 192,512 字节，约 7%。
- 当前镜像的 esptool 信息检查与 RSA 签名校验通过。当前镜像已通过串口烧录后的 Flash 哈希校验。板卡标识为 szpi-s3，镜像声明 ESP-IDF v6.0.2。
- 模型大小为 7,557,640 字节，SHA-256 为 50bed3e16a6b11f3496dde21d8784da9067f40ec9f0a77cf97f60a95acb80f6b，与上游声明一致。应用 tokenizer 与模型配套文件一致。
- 正常 flash 清单包含 0x290000 的模型分区。后续实机调试使用 app-flash 更新应用。
- Python 工具脚本语法检查、翻译格式参数检查、字库覆盖检查和 git diff --check 通过。

## 板上验证

- 使用 COM33 CH340K 连接，读到 ESP32-S3 v0.2、16 MB Flash、8 MB Octal PSRAM。
- 按官方第 9 章 LCD 初始化流程制作独立测试，用户确认红、绿、蓝、白四色正常。已回接鱼缸程序，用户确认画面和触摸正常。
- 本地模型加载成功并持续生成决策。早期运行日志记录约 11–14 tok/s，每次决策约 3–4 秒。
- 已有鱼名、成长数据及设置随应用更新继续载入。当前两条鱼，上限三条。
- 首次默认音量为 0，已通过启动日志确认。测试末尾通过 snd off 保存静音设置。
- 设置页按实际 LCD 采样栅格回读，中文与按钮完整。图片位于 ../.mklink/board-test-20261111/settings-native.png。

- 2026-11-12 补齐鱼缸库介绍、鱼缸种类卡片、海马停驻状态、版本与构建信息、键盘模式和时间单位。默认鱼缸名称在显示时翻译，自定义名称沿用存档。

- 修复收藏架名牌与鱼缸库介绍的 UTF-8 换行。检查覆盖 763 个界面非 ASCII 字符，缺字为零，翻译脚本重复执行结果一致。

## 性能与范围

当前汉化补丁退出菜单后统计 1,015 帧，平均 22.7 FPS，最长帧间隔 55 毫秒，超过 66 毫秒和 100 毫秒均为零。串口再次确认音量为 0%，随后已停止本轮记录并释放串口。

前一版动画固件连续统计约 275 秒，记录 6,255 帧、平均 22.8 FPS、最长帧间隔 54 毫秒，超过 66 毫秒和 100 毫秒的帧均为零。该窗口为两条鱼、精简日志模式，数据保存于 config-checks.json 与实机 CSV 日志。用户已确认“已顺畅，可以保留这一版”。

水草动画在部分测试窗口回退到实时绘制，仍有约 6–9 毫秒的每帧开销。30 FPS 为当前目标上限，报告采用实际统计值。

前一版游动与转身效果已由用户实机确认。当前汉化补丁已核对设置页和收藏架回读画面，鱼缸库、访客护照和海马状态的页面视觉仍待逐页实测。扬声器播放、双板联机、BOOT 组合操作、姿态翻转、休眠唤醒与长时间满负载尚未完整实测。PC 模拟器测试受本机 MinGW 标准头文件缺失影响，目标板构建与运行已验证。
